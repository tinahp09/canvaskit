# CanvasKit

CanvasKit is a TypeScript-first engine for interactive visual editors on an infinite canvas.

## Current capabilities

CanvasKit provides rectangle, circle, and text scenes; Canvas 2D rendering; pan/zoom navigation; selection primitives; grid snapping; keyboard deletion; and versioned JSON persistence. See [Getting Started](docs/getting-started.md) or run `pnpm --filter @canvaskit/basic-canvas dev`.
