# CanvasKit V5 Production Collaboration Adapters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a browser-ready collaboration-adapters package with transport lifecycle, presence relay, reconnect safety, and a browser-tested reference app.

**Architecture:** `@canvaskit/collaboration-adapters` stays outside Core and only implements Core’s root-export collaboration contracts. A shared envelope codec validates adapter protocol boundaries; BroadcastChannel and injected WebSocket transports share listener/status/outbox semantics but own their platform lifecycle independently.

**Tech Stack:** TypeScript, browser DOM APIs, Vitest, Playwright, Vite, VitePress.

**Spec:** `docs/superpowers/specs/2026-09-02-v5-production-collaboration-adapters-design.md`

## Global Constraints

- No backend, authentication, authorization, persistence, CRDT, or network dependency is added to Core.
- The adapter package imports only public root APIs from `@canvaskit/core`.
- Adapter envelopes are JSON data with protocol version `1`, room filtering, and self-echo rejection.
- WebSocket construction is injected through `WebSocketFactory`; browser globals are never required in unit tests.
- Local outbox delivery is FIFO, capped, observable on overflow, and replayed only after an open socket.
- Presence stays outside `CanvasScene`; malformed input must not notify operation or presence subscribers.
- Use red/green tests before each behavior change. Do not stage `dist`, `.turbo`, `.pnpm-store`, screenshots generated by test failures, or test results.
- Public tags, npm publishing, GitHub Releases, deployment, and posts remain explicit-approval actions.

export function decodeEnvelope(raw: unknown): CollaborationEnvelope | undefined {

```ts
export class BroadcastChannelTransport implements CollaborationAdapter {
  connect(): void { if (this.channel) return; this.channel = this.channelFactory(this.channelName); this.channel.onmessage = this.receive; this.setStatus({ state: 'open' }) }
  publish(operation: CollaborationOperation): void { this.post({ type: 'operation', operation }) }
  publishPresence(snapshot: PresenceSnapshot): void { this.post({ type: 'presence', presence: snapshot }) }
  disconnect(): void { if (!this.channel) return; this.post({ type: 'leave' }); this.channel.close(); this.channel = undefined; this.setStatus({ state: 'closed' }) }
}
```

Use a factory interface instead of referring to the global `BroadcastChannel` in
the constructor. If the default browser API is absent, expose `{ state: 'error',
message: 'BroadcastChannel is unavailable.' }` and do not throw from `connect`.

- [ ] **Step 3: Implement injected socket lifecycle**

```ts
type ReconnectPolicy = { initialDelayMs: number; maxDelayMs: number; maxAttempts: number }

private scheduleReconnect(): void {
  if (!this.shouldReconnect || this.attempt >= this.policy.maxAttempts) return this.setStatus({ state: 'closed' })
  const delay = Math.min(this.policy.maxDelayMs, this.policy.initialDelayMs * 2 ** this.attempt) + stableJitter(this.senderId, this.attempt)
  this.setStatus({ state: 'reconnecting', attempt: this.attempt + 1, retryAt: this.now() + delay })
  this.timer = this.setTimer(() => this.openSocket(), delay)
}
```

Flush the FIFO outbox only inside the open handler. A manually requested
disconnect clears a reconnect timer, sends one leave envelope when open, and
does not reconnect. Decode received `event.data` before listener notification.
