# CanvasKit v6.0.0 release asset manifest

Release evidence is captured from `examples/editor-session` and committed in
`docs/public/releases/v6/`:

- `v6.0-overview.png`: two-document glassy workspace at a clean baseline.
- `v6.0-dirty-tabs.png`: a changed active document with its independent dirty
  indicator.
- `v6.0-command-palette.png`: active-document command palette after a
  selectable shape is present.
- `v6.0-editor-session.gif`: a 5–15 second sequence of tab switching, adding
  a rectangle, and selecting it through the palette.

The same workflow is covered by the committed Playwright E2E suite.
